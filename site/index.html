Install in two minutes

Terminal 
$ git clone https://github.com/itchyparrot53/tuesday..git
$ cd tuesday
$ cp .env.example .env    # set APP_URL; OPENROUTER_API_KEY is optional
$ docker compose up -d --build

Open http://localhost:3000 and create the owner account. There's no default login.

What you need

  • Docker Engine 24+ with Compose
  • About 2 GB of RAM and a persistent volume
  • A domain with HTTPS for anything beyond localhost

Questions, answered.

Is Tuesday free?

Yes. MIT, no paid tier and no features held back.

Is there a hosted version?

No. It runs on your server. No Tuesday cloud, no account with us.

Do I need AI?

No. Without a key, AI features are hidden and nothing leaves your server. With a key, you set the limits.

What does it need to run?

Docker Engine 24+ with Compose, about 2 GB of RAM and a persistent volume. HTTPS for real use.

How many people can use it?

A few people up to about fifty on one server. Single-node SQLite, no clustering.

Can I move from monday.com or a spreadsheet?

Export boards to CSV, import them, then rebuild views and automations.

How do backups work?

Automatic local archives, encrypted copies to any S3-compatible bucket, and a restore drill.

Is it ready for production?

It's a public beta. APIs may change before 1.0. Back up and pin a release tag.

Is Tuesday affiliated with monday.com?

No. It's independent and not affiliated with, endorsed by or connected to monday.com.
